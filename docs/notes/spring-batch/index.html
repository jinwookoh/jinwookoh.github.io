Spring Batch

배치 처리 프레임워크의 도메인 모델·Job과 Step·오류 처리·Reader/Writer·확장·테스트와 운영까지.

20편

개념

  1. 1Spring Batch란 — 아키텍처와 도메인 언어대량 일괄 처리의 재시작·트랜잭션·통계를 프레임워크가 맡는 구조를 3계층과 Job·Step·Chunk 어휘로 읽는다.
  2. 2첫 Job — Infrastructure 설정과 v5/v6 변경 사항Spring Boot 위에서 첫 Job을 띄우는 최소 설정과 v4→v5→v6에서 @EnableBatchProcessing·Builder·JobRepository가 바뀐 지점을 정리한다.

Job과 실행

  1. 3Job 설정 — JobBuilder·Validator·ListenerJobBuilder로 Step 흐름·재시작 정책·파라미터 검증·Incrementer·Listener를 한 번에 정의하는 방법
  2. 4JobRepository와 메타데이터 스키마JobRepository가 실행 상태를 어떤 테이블에 저장하고, 재시작·동시 실행 차단이 그 스키마 위에서 어떻게 성립하는가
  3. 5Job 실행 — JobLauncher·JobOperator·JobExplorerJob을 띄우고 멈추고 다시 돌리는 세 인터페이스의 역할 분담과 동기·비동기 실행, JobParameters 식별 규칙을 정리한다.

Step

  1. 6Step — Chunk 지향과 Tasklet·Commit IntervalStep은 chunk 지향과 Tasklet 두 방식으로 동작하며, chunk 크기가 곧 트랜잭션 경계이자 성능 튜닝의 핵심이다.
  2. 7Step 재시작과 ItemStream재시작이 실패 지점부터 이어지려면 Step 재시작 설정과 ItemStream 등록이 함께 맞아야 한다
  3. 8Flow 제어 — Decision·Split·Late BindingExitStatus·Decider·Split으로 Job 흐름을 분기·병렬화하고, 실행 시점 값을 @StepScope로 주입하는 방법
  4. 9Step ListenerStep 실행 사이클에 끼어드는 Listener 6종의 호출 시점과 트랜잭션 커밋 전후 위치를 정리한다

오류 처리와 트랜잭션

  1. 10Skip과 Retry영구적 데이터 오류는 Skip, 일시적 오류는 Retry — faultTolerant 이후 두 정책이 단계별로 어떻게 동작하는지 정리한다
  2. 11트랜잭션 속성과 Repeatchunk 트랜잭션의 격리·전파·타임아웃을 어떻게 잡고, 그 아래에서 도는 RepeatTemplate을 어떻게 직접 쓰는가

Reader·Processor·Writer

  1. 12ItemReader·ItemWriter 인터페이스와 구현체 카탈로그read()의 null 종료·forward-only 계약과 write(Chunk)의 멱등성 책임을 기준으로 표준 구현체를 고르는 법
  2. 13Flat File Reader·WriterCSV·고정 길이 파일을 Tokenizer→FieldSet→Mapper 3단계로 읽고 역방향으로 쓰는 구조와 재시작·트랜잭션 함정
  3. 14XML·JSON·Multi-file 입출력XML·JSON도 fragment·object 단위로 스트리밍하고, 여러 파일은 delegate 하나로 묶어 재시작 위치까지 추적한다
  4. 15Database Reader·Writer — Cursor vs PagingDB 읽기는 Cursor와 Paging 중 무엇을 고르고, 쓰기는 왜 JdbcBatchItemWriter와 UPSERT가 기본인지 정리한다
  5. 16ItemProcessor·서비스 재사용·커스텀 구현ItemProcessor의 null·예외 분기, 기존 서비스를 Adapter로 감싸는 조건, 커스텀 Reader·Writer의 재시작 안전성 확보 방법을 정리한다.

확장과 운영

  1. 17Scaling — Multi-thread·Partitioning·Remote Chunking병목 위치에 따라 Multi-threaded Step·AsyncItemProcessor·Partitioning·Remote Chunking 중 무엇을 고를지 정리한다
  2. 18Spring Batch Integration — 메시지로 Job 실행파일 도착·Kafka 메시지 같은 이벤트를 Job 실행 트리거로 바꾸고, 진행 상태를 메시지 채널로 내보내는 방법
  3. 19테스트와 관측성 — @SpringBatchTest·Micrometer·JFRJob을 테스트로 검증하고, 운영 중에는 Micrometer 메트릭과 JFR 이벤트로 무엇이 왜 느린지 찾는 방법
  4. 20운영 패턴과 FAQJob 중단·Footer 집계·Driving Query·Step 간 데이터 전달 패턴과 재실행·Chunk 크기·스케줄링 FAQ를 정리한다

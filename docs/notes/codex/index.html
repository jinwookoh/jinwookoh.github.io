Codex

OpenAI의 코딩 에이전트 — CLI·IDE·클라우드, AGENTS.md·샌드박스·승인 모드, MCP·커스텀 프롬프트, CI 자동화.

9편

기초

  1. 1Codex란 무엇인가 — CLI·IDE·클라우드Codex는 터미널·에디터·클라우드라는 세 표면이 같은 설정과 권한 모델을 공유하는 코딩 에이전트다
  2. 2설치와 config.toml 설정Codex 설정은 CLI 플래그부터 내장 기본값까지 6단계로 겹쳐지며, 계층을 알아야 값이 왜 안 먹는지 설명된다
  3. 3AGENTS.md — 프로젝트 규칙을 에이전트에게 전달AGENTS.md는 전역과 디렉터리별 파일이 루트에서 아래로 병합되는 지시문 체인이며, 가까운 파일이 이긴다
  4. 4샌드박스와 승인 모드 — 안전한 자율 실행샌드박스는 할 수 있는 범위를, 승인 정책은 멈춰 묻는 시점을 정하며 둘은 독립적으로 조합된다

확장

  1. 5MCP 서버 연동Codex가 저장소 밖 시스템을 도구로 끌어오는 통로인 MCP를 config.toml 설정과 승인·타임아웃 기준으로 정리한다
  2. 6커스텀 프롬프트와 확장 — 슬래시 커맨드·프로필반복 지시를 슬래시 커맨드와 스킬로 묶고 실행 설정을 프로필로 분리하는 방법, 그리고 우선순위 함정을 정리한다
  3. 9Codex 스킬 생태계 — Superpowers식 워크플로 만들기Codex의 확장 표면은 스킬·AGENTS.md·MCP·플러그인 네 층이며, 이것만으로 규율 있는 워크플로를 조립하는 방법을 정리한다

운영

  1. 7Codex Cloud와 CI 자동화 — exec·GitHub 연동대화형 세션 밖에서 Codex를 돌리는 두 경로인 codex exec와 Codex Cloud를, 출력 처리와 권한 통제 중심으로 정리한다
  2. 8운영 팁 — 모델 선택·비용·팀 도입모델과 추론 강도를 작업 성격에 맞춰 나누고, 5시간 한도와 조직 설정 계층을 기준으로 팀 도입을 설계하는 방법을 정리한다

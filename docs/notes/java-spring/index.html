Java / Spring

자바 언어 기초부터 Spring Boot 3 기반 백엔드의 코어·웹·데이터·운영까지.

40편

자바 기초·모던 자바

  1. 1자바 백엔드 개관 — JVM·객체와 클래스·OOP 4기둥자바가 JVM 위에서 어떻게 실행되고, 클래스·객체와 OOP 4기둥이 Spring Bean 설계의 전제가 되는 이유를 정리한다.
  2. 2인터페이스·다형성·SOLID인터페이스와 다형성이 구현체 교체를 가능하게 하고, SOLID 5원칙이 그 교체를 안전하게 만드는 규칙임을 정리한다.
  3. 3컬렉션·제네릭·Optional여러 객체를 담는 컬렉션, 담기는 타입을 컴파일 시점에 고정하는 제네릭, 없을 수 있는 반환값을 표현하는 Optional을 한 번에 정리한다.
  4. 4예외 처리체크드와 언체크드 예외의 경계를 정확히 긋고, try-with-resources와 예외 체이닝으로 자원 누수와 원인 소실을 막는 방법을 정리한다.
  5. 5람다·함수형 인터페이스·Stream람다는 함수형 인터페이스의 인스턴스이고, Stream은 그 람다를 받아 컬렉션을 선언적으로 처리하는 일회용 지연 파이프라인이다.
  6. 6Modern Java 9~21 핵심Java 9~21에서 실무 코드를 바꾼 언어·API 변화를 LTS 기준으로 묶어 정리한다
  7. 7Virtual Thread — 원리·API·PinningVirtual Thread가 Carrier 위에서 mount·unmount하는 원리, 생성 API 4가지, synchronized가 일으키는 Pinning의 원인과 대응을 정리한다.
  8. 8Virtual Thread — 실전·Spring Boot·Structured ConcurrencySpring Boot 설정 한 줄로 Virtual Thread를 켠 뒤, 병렬 호출·외부 자원 보호·측정을 어떻게 설계하는가
  9. 9디자인 패턴 — 생성·구조객체를 어떻게 만들고(생성) 어떻게 조합하는지(구조)를 GoF 11개 패턴의 적용 신호와 함정 중심으로 정리한다.
  10. 10디자인 패턴 — 행위·조합행위 패턴 9가지의 역할 분담 원칙과 Observer·Strategy·Mediator를 한 시스템에 조합하는 기준을 정리한다

Spring 코어

  1. 11빌드·프로젝트 구성 — Maven/Gradle·start.spring.io·Profiles빌드 도구가 의존성을 해석하고, Initializr가 표준 골격을 만들며, Profile과 외부 설정이 환경 차이를 코드 밖으로 밀어내는 구조를 정리한다.
  2. 12Spring Framework와 Boot 자동 구성Spring Boot는 Framework를 대체하지 않으며, 클래스패스와 조건 어노테이션으로 인프라 Bean을 채우는 래퍼다
  3. 13IoC/DI와 ApplicationContext — Bean이란객체 생성과 연결의 책임을 컨테이너로 넘기는 IoC/DI의 원리와, ApplicationContext가 Bean을 다루는 방식을 정리한다.
  4. 14Bean 등록과 주입 — 어노테이션·@Component·@Configuration어노테이션이 리플렉션으로 읽히는 원리부터 @Component 스캔·@Bean 팩토리·생성자 주입·@Primary/@Qualifier 분기까지 정리한다
  5. 15Bean Scope와 생명주기Bean을 몇 개 만들고 언제 초기화·소멸시키는지 결정하는 Scope와 콜백의 동작 규칙
  6. 16AOP와 SpEL횡단 관심사를 프록시로 분리하는 Spring AOP의 동작 원리와 SpEL 표현식의 역할·경계를 정리한다
  7. 17계층 설계 — 서비스 레이어 분리Controller·Service·Repository 3계층의 책임과 의존 방향, 비즈니스 로직과 트랜잭션 경계를 서비스에 두는 이유

Web MVC

  1. 18요청 처리 흐름 — DispatcherServlet·Filter·InterceptorHTTP 요청이 Tomcat에서 컨트롤러까지 거치는 단계와 Filter·Interceptor가 갈리는 지점을 정리한다.
  2. 19Controller와 요청 바인딩HTTP 요청의 경로·쿼리·본문을 메서드 인자로 받고, 반환 객체를 JSON 응답으로 내보내는 Spring MVC의 바인딩 규칙
  3. 20ArgumentResolver·파일 업로드·페이징컨트롤러 매개변수를 채우는 HandlerMethodArgumentResolver 원리와 MultipartFile 업로드·Pageable 페이징의 안전한 사용법
  4. 21예외 처리와 검증 — @ControllerAdvice·Bean Validation컨트롤러에서 try-catch와 if 검증을 걷어내고, 글로벌 핸들러와 검증 어노테이션으로 오류 응답을 한 형식으로 통일하는 방법
  5. 22CORS와 Spring Security — OAuth2·JWTCORS 허용 헤더, SecurityFilterChain 인증·인가, 그리고 JWT를 공개 키로 검증하는 OAuth2 Resource Server 구성을 정리한다.
  6. 23API 문서화 — Springdoc OpenAPISpringdoc이 컨트롤러 코드에서 OpenAPI 명세를 생성하는 원리와 어노테이션 보강·보안 스키마·운영 노출 통제 방법

데이터

  1. 24JDBC·DataSource·JdbcTemplateJDBC 표준 위에 DataSource로 커넥션을 풀링하고 JdbcTemplate으로 보일러플레이트와 예외를 제거하는 구조
  2. 25@Transactional 원리와 낙관/비관 락@Transactional은 원자성만 보장하며 동시 수정 충돌은 @Version 낙관적 락이나 @Lock 비관적 락으로 따로 막는다.
  3. 26JPA·Hibernate·Spring Data JPA — Entity와 RepositoryJPA는 표준, Hibernate는 구현체, Spring Data JPA는 Repository 추상화이며 코드의 두 축은 @Entity와 JpaRepository다.
  4. 27연관관계·N+1·값 객체외래 키를 가진 쪽이 연관관계의 주인이며, 모든 관계를 LAZY로 두고 Fetch Join으로 N+1을 끊고, 식별자 없는 값은 @Embeddable로 묶는다.
  5. 28쿼리 — 메서드 이름·@Query·QueryDSL·Auditing단순 조건은 메서드 이름, 조인은 @Query, 동적 조건은 QueryDSL로 나누고 생성·수정 이력은 Auditing에 맡긴다
  6. 29영속성 컨텍스트와 LazyLoading영속성 컨텍스트는 트랜잭션 범위의 1차 캐시이며, LazyInitializationException과 N+1은 이 범위를 벗어난 지연 로딩에서 발생한다
  7. 30캐싱 — @Cacheable과 Spring Data Redis@Cacheable·@CachePut·@CacheEvict로 메서드 결과를 캐싱하고, Redis 연동 시 TTL·직렬화·자기 호출 함정을 어떻게 다루는가

운영·통합

  1. 31로깅 — Logback·SLF4J코드는 SLF4J 파사드만 의존하고 Logback이 출력을 맡는 구조에서 레벨·롤링·MDC 추적 ID를 어떻게 잡는가
  2. 32이벤트·비동기·스케줄링부가 작업을 도메인 이벤트로 분리하고 @Async 스레드 풀과 @Scheduled 분산 락으로 안전하게 운영하는 방법
  3. 33HTTP 클라이언트 — RestClientSpring 6.1+ 동기 호출 표준 RestClient의 빌더·상태 코드 매핑·타임아웃·인터셉터·테스트 패턴을 정리한다
  4. 34테스트 — MockMvc·@SpringBootTest·Testcontainers·Flyway슬라이스·통합·실제 DB 테스트를 어떤 기준으로 나누고, Testcontainers와 Flyway로 운영과 같은 환경을 재현하는가
  5. 35Actuator와 MicrometerActuator 엔드포인트로 상태를 노출하고 Micrometer로 메트릭·트레이스를 수집해 운영 가시성을 확보하는 방법
  6. 36DTO 매핑 — MapStructEntity와 DTO 사이 변환 코드를 컴파일 시점에 생성해 반복과 누락을 없애는 MapStruct 표준 패턴
  7. 37배포 — Docker·BuildpackSpring Boot 앱을 컨테이너 이미지로 만드는 두 경로(Buildpack·Dockerfile)와 Compose·Kubernetes 운영 시 확인할 지점을 정리한다.
  8. 38MSA 입문 — Spring Kafka·Cloud Gateway서비스를 쪼갠 뒤 안쪽은 Kafka 이벤트로, 바깥쪽은 Gateway 단일 진입점으로 잇는 최소 구성을 정리한다
  9. 39Spring AIChatClient·PromptTemplate·VectorStore로 LLM 호출과 RAG를 Spring 방식으로 통합하는 법
  10. 40베스트 프랙티스 정리Spring Boot 3 실무 규칙을 DI·프록시·보안·성능·테스트 축으로 압축하고, 가장 자주 틀리는 패턴의 원인을 정리한다.

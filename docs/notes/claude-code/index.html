Claude Code

Anthropic의 CLI 코딩 에이전트 — CLAUDE.md·권한 모델, 스킬·서브에이전트·훅·MCP·플러그인, SDK와 CI 자동화.

11편

기초

  1. 1Claude Code란 무엇인가 — 설치와 기본 사용법Claude Code는 저장소를 직접 읽고 고치고 명령을 실행하는 터미널 에이전트이며, 도입의 관문은 권한 모델이다
  2. 2CLAUDE.md와 메모리 — 프로젝트 컨텍스트 관리CLAUDE.md는 매 세션 로딩되는 컨텍스트일 뿐 강제 설정이 아니므로, 분량과 배치가 준수율을 결정한다
  3. 3설정과 권한 모델 — settings.json·permission mode권한 규칙은 deny·ask·allow 순으로 첫 일치가 결과를 결정하며, 와일드카드 위치가 허용 범위를 좌우한다

확장

  1. 4스킬과 슬래시 커맨드스킬은 필요할 때만 컨텍스트에 들어오는 절차 묶음이며, 프런트매터가 호출 주체와 도구 권한을 결정한다
  2. 5서브에이전트 — 작업 분리와 병렬화독립 컨텍스트와 도구 제한을 가진 서브에이전트로 탐색·검증 작업을 본 대화에서 떼어내는 방법을 정리한다.
  3. 6훅 — 도구 호출 전후 자동화모델의 판단에 맡기지 않고 포맷·차단·감사를 결정론적으로 강제하는 훅의 이벤트·입출력 규약을 정리한다.
  4. 7MCP 서버 연동 — 외부 도구와 데이터 연결이슈 트래커·DB·사내 API를 표준 프로토콜로 붙이는 MCP의 전송·스코프·네이밍 규약과 운영상 한도를 정리한다.
  5. 8플러그인 — 마켓플레이스와 추천 플러그인스킬·훅·MCP 묶음에 이름과 버전을 붙여 설치 가능한 단위로 만들고 팀에 배포하는 방법
  6. 11Superpowers — 워크플로 스킬 플러그인과 비슷한 도구들설계·계획·TDD·검증 순서를 사람의 말 대신 자동 트리거 스킬로 고정하는 플러그인의 동작 원리와 대가

운영

  1. 9Agent SDK와 headless 모드 — CI 자동화claude -p 와 Agent SDK로 사람이 지켜보지 않는 파이프라인 안에 에이전트를 넣는 방법
  2. 10실무 워크플로 — 계획·TDD·비용 관리컨텍스트를 유한한 자원으로 다루는 계획·검증·정리 습관과 토큰 비용을 줄이는 조치

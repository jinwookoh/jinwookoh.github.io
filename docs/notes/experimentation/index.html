실험과 분석

확률·통계 기초에서 A/B 테스트 설계와 통계, Statsig 실험 플랫폼, GA4 측정·전환·BigQuery까지.

15편

통계 기초

  1. 1확률 기초와 기술통계실험 결과를 읽기 전에 알아야 할 중심·산포 측도와 조건부 확률·베이즈 정리를 정리한다
  2. 2확률 분포·가설 검정·신뢰구간표본 하나로 모집단을 말할 수 있는 근거는 분포 가정과 CLT이며, p-value와 신뢰구간은 그 위에서만 의미를 가진다.
  3. 3회귀·ANOVA·카이제곱두 변수의 관계는 회귀로, 세 그룹 이상의 평균은 ANOVA로, 범주형 빈도는 카이제곱으로 검정하는 기준을 정리한다

A/B 테스트

  1. 4A/B 테스트 — 대조군·전환율·가설과 지표 설계무작위 동시 배정·고정 버케팅·이진 지표·사전 종료 기준이 갖춰져야 A/B 테스트 결과를 의사결정 근거로 쓸 수 있다
  2. 5A/B 테스트 통계 — 카이제곱·베이지안·다중 비교전환율 차이가 우연인지 판정하는 카이제곱 검정과 p-value의 정확한 의미, Peeking·다중 비교 함정과 베이지안 대안을 정리한다.
  3. 6A/B 테스트 시스템 — Feature Flag와 실험 플랫폼 구현배정·플래그 평가·이벤트 추적·결과 집계를 분리해 A/B 테스트 플랫폼을 직접 구현하는 방법
  4. 7A/B 테스트 베스트 프랙티스와 사례실험 코드를 안전하게 짜고, 결과를 트레이드오프까지 보고 판단하며, 종료 후 정리하는 실무 원칙과 사례

Statsig

  1. 8Statsig 개관과 SDK QuickstartStatsig의 네 축과 Cloud/Warehouse Native 구분을 정리하고 Java Server SDK로 첫 Feature Gate를 연결한다
  2. 9Feature Flags와 ExperimentsGate의 순차 Targeting·Holdout으로 출시를 제어하고, Experiment의 Layer·SRM·순차 검정으로 인과를 검증하는 방법
  3. 10Product Analytics와 Warehouse Native이벤트 설계와 6종 차트, 그리고 데이터를 자사 웨어하우스에 둔 채 Statsig 통계 엔진을 쓰는 WHN 운영을 정리한다
  4. 11통합·운영·도입 결정Statsig를 사내 도구와 연결하는 통합 계층, 부수 기능의 비용·privacy, 도입 여부를 가르는 결정 기준을 정리한다.

GA4

  1. 12GA4 데이터 모델 — 이벤트·세션·사용자GA4는 모든 상호작용을 이벤트로 기록하고, Client ID·User ID·세션 규칙으로 사용자와 방문을 묶는다.
  2. 13측정 구현 — gtag·GTM·이벤트·전자상거래gtag·GTM·Measurement Protocol의 역할을 나누고, 표준 이름과 items 구조로 전자상거래 퍼널을 깨지지 않게 구현한다
  3. 14전환·잠재고객·보고서·탐색이벤트를 키 이벤트로 승격하고 잠재고객·탐색·기여 분석으로 비즈니스 가치를 읽어내는 절차를 정리한다
  4. 15BigQuery Export·API·운영과 PrivacyGA4 데이터를 UI 밖으로 꺼내 쓰는 세 경로와, 운영에서 반드시 마주치는 한도·동의·PII 문제를 정리한다

실전 프로젝트 — SNS 마이크로서비스

Spring Boot 기반 SNS를 마이크로서비스로 설계하고 인증·동시성·이벤트·검색·파일 업로드를 실제 구성으로 풀어낸 기록.

5편

아키텍처

  1. 1서비스 분해와 아키텍처SNS를 서비스 4개로 나누고 Database-per-Service·Gateway·Kafka·Healthcheck로 묶는 기준을 정리한다

인증

  1. 2API Gateway·JWT·OAuth2 인증게이트웨이 한 곳에서 JWT를 검증하고 User Service가 토큰 발급·OAuth2 매핑을 맡는 stateless 인증 구조를 정리한다.

서비스

  1. 3게시물 서비스 — Redisson 분산 락과 동시성락은 트랜잭션 바깥에, 외부 시스템 갱신은 afterCommit 안에 두어야 게시글 중복 생성과 유령 데이터를 막을 수 있다.

데이터와 검색

  1. 4Kafka 이벤트 흐름·Outbox·Redis 활용 패턴DB 커밋과 Kafka 발행을 Outbox·Debezium으로 묶고, Redis 하나로 캐시·랭킹·블랙리스트·락을 나눠 맡긴다
  2. 5Elasticsearch 검색과 S3 업로드DB를 진실의 원천으로 두고 검색 인덱싱과 파일 업로드를 트랜잭션 바깥으로 분리하는 방법

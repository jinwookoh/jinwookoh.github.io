Flutter

위젯 트리와 렌더링, Dart 핵심, 레이아웃, 상태 관리, 내비게이션, 네트워크와 저장소, 네이티브 연동, 테스트와 배포.

10편

기초

  1. 1Flutter란 — 위젯 트리와 렌더링Flutter가 플랫폼 UI 컴포넌트 대신 자체 렌더러와 위젯·엘리먼트·렌더 세 트리로 화면을 그리는 구조를 정리한다
  2. 2Dart 핵심 — null safety·async·컬렉션Dart 3의 sound null safety·Future/Stream 비동기·컬렉션 리터럴을 Flutter 코드 읽기에 필요한 만큼 정리한다

위젯과 상태

  1. 3위젯과 레이아웃 — Stateless/Stateful·Row/Column/Stack위젯은 불변 설계도이고 상태는 State가 들고 있으며, 크기는 부모 제약이 결정한다
  2. 4상태 관리 — setState·InheritedWidget·Provider·Riverpod상태를 어디에 두고 누가 다시 그릴지를 setState·InheritedWidget·Provider·Riverpod 단계별로 정리한다
  3. 5내비게이션 — Navigator·go_router명령형 Navigator와 선언적 go_router의 차이, 그리고 딥링크·리다이렉트·탭 셸을 URL 기반으로 다루는 방법을 정리한다.

데이터와 플랫폼

  1. 6네트워크·JSON 직렬화http 패키지로 요청을 보내고 dart:convert와 json_serializable로 JSON을 타입 안전한 모델로 바꾸는 방법을 정리한다.
  2. 7로컬 저장 — SharedPreferences·SQLite·파일설정값은 shared_preferences, 구조화 데이터는 sqflite, 큰 덩어리는 path_provider 파일로 나눠 저장한다
  3. 8플랫폼 채널과 네이티브 연동·권한Dart 코드가 못 건드리는 OS 기능은 MethodChannel·EventChannel·플러그인으로 네이티브에 위임하고, 권한은 플랫폼 쪽에서 처리한다

NestJS

모듈·컨트롤러·프로바이더와 DI, Pipe·Guard·Interceptor, 데이터베이스와 큐, 마이크로서비스, 테스트와 배포 — Spring 개발자 관점.

10편

기초

  1. 1NestJS란 — 모듈·컨트롤러·프로바이더NestJS는 모듈·컨트롤러·프로바이더 세 축과 DI 컨테이너로 Node 서버에 Spring식 구조를 부여한다
  2. 2DI와 모듈 시스템NestJS 모듈이 프로바이더의 가시성을 어떻게 가르고, 커스텀 프로바이더와 스코프가 인스턴스 생성을 어떻게 바꾸는지 정리한다

요청 처리

  1. 3Pipes·검증·DTOPipe는 핸들러 진입 직전에 인자를 변환·검증하는 계층이며, ValidationPipe와 DTO 조합이 입력 검증의 표준이다
  2. 4Guards·인증 — Passport·JWTGuard는 핸들러 실행 전 요청의 자격을 판정하는 단일 지점이며, JWT 인증과 역할 인가를 여기서 분리해 처리한다.
  3. 5Interceptors·Exception Filters·Middleware요청 파이프라인의 세 가로축 — 어디서 무엇을 자르고, 무엇을 감싸고, 예외를 어디서 받는가

데이터와 인프라

  1. 6데이터베이스 — TypeORM·Prisma·트랜잭션NestJS에서 TypeORM과 Prisma를 DI 컨테이너에 올리는 방식과 트랜잭션 경계를 어디서 잡는지 정리한다
  2. 7설정·환경·로깅환경 변수를 검증된 타입 객체로 주입하고, 부트스트랩 로그까지 한 로거로 모으는 방법을 정리한다
  3. 8캐싱·큐(BullMQ)·스케줄링요청 경로에서 빼야 할 세 가지 일 — 반복 조회는 캐시로, 느린 작업은 큐로, 주기 작업은 스케줄러로 옮기는 방법

운영

  1. 9마이크로서비스 — Kafka·gRPCNestJS 마이크로서비스 추상화 위에서 Kafka 이벤트와 gRPC 호출을 어떻게 나눠 쓰고 어디서 걸리는지 정리한다
  2. 10테스트와 배포TestingModule로 의존성을 교체해 단위·e2e 테스트를 짜고, 빌드 산출물을 컨테이너로 안전하게 종료·배포하는 방법을 정리한다.
